# Profit Calculation System

A Python desktop application for business profit analysis, built as a Software Engineering course project.

## Features

- Transaction and cost center management
- SQLite database persistence
- Dashboard with matplotlib charts
- What-if sensitivity simulator
- ETL pipeline for CSV import
- Break-even analysis per product
- Excel export

## Requirements

- Python 3.9+
- pip install matplotlib pandas openpyxl

## Run

python main.py
